# Forest Bandit

A small, complete woodland scavenging game. You are a raccoon with a little satchel and four neighbours who need almost-useful things. Find their ingredients, bring them home, deliver requests, and unlock pond fishing, ruin digging, extra storage, longer days, and a lucky charm. Finish all four requests to become an honorary Forest Bandit, then keep collecting the rare keepsakes.

## Play locally

From the UltraLoot repository, run `npm ci` and `npm run ci`, then serve `docs/` using an HTTP server. For example:

```sh
python3 -m http.server 8765 --directory docs --bind 127.0.0.1
```

Open `http://127.0.0.1:8765/examples/forest-bandit/`. No external fonts, game engine, audio, or CDN is required. The local UltraLoot browser bundle at `docs/js/ultraloot.js` is generated by `npm run ci`; it is intentionally not tracked. Published documentation builds copy the same bundle.

## Controls and rules

- WASD or arrow keys to walk; E or Space to interact. Focus the map for keyboard controls.
- Click/tap the map or a destination button to walk there. Arriving at a destination searches it; Head home returns safely without spending daylight.
- Each search spends daylight. Each place can be searched three times per day. Walking has no time limit.
- Choose which finds to pack. Quantities count towards your satchel capacity; partial stacks can be kept when space is limited. Excess finds are left only when you explicitly choose to leave them.
- At home, stash your satchel, deliver neighbour requests, buy upgrades, trade spare finds, or sleep to refresh daylight and search spots. Sleeping also stashes your satchel.
- Trading preserves ingredients for unfinished requests and the crown/firefly keepsakes. Sparkly items sell for double.
- The pond requires a net, and the ruins require a trowel. An early request pays for the net.
- Sound is optional and generated locally with Web Audio. Reduced-motion mode removes decorative animation and makes destination travel instant.

Progress is automatically saved to localStorage on this browser and origin, including pending backpack decisions and exact RNG state. Closing/reloading resumes the adventure. Saves are validated before use. Clearing browser storage loses the save; this example has no server or cloud account. Starting a new seed explicitly replaces the local adventure.

## The UltraLoot example

`world.mjs` contains data and game rules independently of rendering:

- Six local loot tables include guaranteed biome ingredients and a bonus pool.
- A shared nested shiny-item table demonstrates reusable child tables.
- Registered conditions use weather and the player's collection to gate fireflies and unique keepsakes.
- A modifier applies sparkly trade quality and extra berries/honeycaps in drizzle.
- One seeded UltraLoot RNG continues across searches and is serialized after each roll. The same seed and search/action history reproduce outcomes within this game/rules version; changing the seed, search order, tools, weather, or rules can change them. Decorative animation never consumes gameplay randomness.
- The “Peek behind the randomness” drawer shows actual choices, conditions, modifiers, and RNG snapshots from the most recent search. Traces are session-only to keep saves small.

`app.js` handles input, dialogs, notebook pages, rendering, and local saves. `pixels.mjs` draws original tiny item/animal icons on a 16-pixel grid. Canvas map controls have equivalent destination buttons; dialogs and notebook tabs support keyboard operation. The two larger generated assets are local PNGs; their production prompts are recorded in [assets/README.md](assets/README.md).

Run `npm run test:forest-bandit` after building, or `npm run check` for the full package checks. The game tests cover deterministic save/resume, every biome, integer quantities, action gates, partial packing, one-time deliveries, safe trading, bounded upgrades, weather/collection callbacks, damaged saves, and complete seeded playthroughs.
